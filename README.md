# Sticker Creator

An interactive sticker creator web page where you can upload a photo, customize it with border, shadow, shape and export options - all this directly on teh browser.

## Features
- Image upload via button or file input.
- Zoom and drag inside the canvas using the mouse.
- Customizable border: thickness and color.
- Customizable shadow: X/Y offset, blur, opacity and color.
- Shape clipping: square, circle, rounded (with adjustable radius) and hexagon.
- Export to PNG, JPEG or WebP at 512x512, 256x256 or 128x128.
- Live numeric values displayed next to each slider control.
